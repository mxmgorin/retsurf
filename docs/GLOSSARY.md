# Glossary

What each of retsurf's screens, controls and modes is.

## Screens and modes

Each is one screen or mode with a name of its own, capitalized as the app writes it.

| Name | What it is |
| --- | --- |
| **Home** | The built-in page that shows the bookmarks as tiles |
| **Menu** | The strip at the left edge: places to go |
| **Quick Access** | The strip at the right edge: actions on what is shown, and the way in and out of Game Mode |
| **Hub** | The full-screen view of the browser's lists, a section for each |
| **Settings** | The full-screen settings, a section for each area |
| **Game Mode** | A tab run as a game: input goes to the page through an input map |

## Parts of the screen

Kinds of things, written in lowercase.

| Term | What it is |
| --- | --- |
| **toolbar** | The bar with the address field and the browser's buttons |
| **chip** | A small toolbar button that shows a state |
| **indicator** | A count or progress beside what it counts |
| **search picker** | The control that picks the search engine |
| **strip** | Menu or Quick Access: a full-height column at a screen edge |
| **section** | One part of the Hub or Settings |
| **tab** | A browser tab |
| **tile** | A bookmark as Home shows it |
| **filter** | A choice on Home that narrows the tiles |
| **overlay** | A screen over the page that takes the controls while open |
| **prompt** | A page's own dialog or picker, shown over the page |
| **toast** | A short message that fades on its own |
| **update notice** | The card that offers a newer release |
| **cursor** | The pointer a pad moves over the page |
| **link hints** | Marks over the page's clickable elements, to click one without the cursor |
| **hint code** | The letters or buttons on a link hint, typed to click it |
| **button hints** | The line at the foot of a screen naming what the buttons do |
| **on-screen keyboard** | retsurf's keyboard for typing with a pad (OSK) |
| **system keyboard** | Android's own keyboard |

## Controls

| Term | What it is |
| --- | --- |
| **gesture** | A tap, hold or chord of buttons or keys |
| **action** | Something the browser does on a gesture |
| **binding** | A gesture paired with an action |
| **stick role** | What the D-pad or a stick does on a page |
| **input map** | What the pad and keys send to a game in Game Mode |
| **input map screens** | The screens that list and edit input maps |

## Pages and bookmarks

| Term | What it is |
| --- | --- |
| **home page** | The page the Home button and new tabs open; Home by default |
| **bookmark** | A saved site, shown as a tile on Home and in the Hub |
| **launch mode** | How a bookmark opens: with the browser around it, or on its own |
| **site settings** | Settings a bookmark keeps for its own site, in force while the site is open |
| **kiosk** | A game run on its own from the command line, with no browser around it |
| **local site** | A folder or HTML file opened from the command line as a site of its own |
